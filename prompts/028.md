Let's try to harmonize the flapping of nearby birds:

CheckNeighbors needs out-parameters for the flap rate and flap phase of the nearest bird.

If TargetDistance > CloseNeighborRange, the new out-parameters should be zero.

If CheckNeighbors yielded a nonzero flap rate, the current bird should adjust its flap rate to match the nearest bird, with a maximum rate-of-change of 0.5 hz per second. If the target flap rate is zero, the current bird's flap rate should return to its original flap rate.

If the current bird's flap rate is within 10% of the target rate, it should maintain the current flap rate until the current bird's phase is within 10% of the target's phase.
