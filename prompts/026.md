The code in simulation.wgsl appears to recalculate the distances between all birds every time it updates the state of each individual bird. Is that true? (Yes.)

This should be faster if we factor out the distance calculation so that it happens either once per simulation step or perhaps once per 64-bird tile. Which would be better? (Selected Claude Sonnet for this, just to be sure.)

"A distance costs about 5 flops: three subtractions and a dot product. Reading a stored distance is a global-memory load, which is far slower than recomputing it. [...] It also can't replace the later tests, which depend on each bird's own direction: the forward-hemisphere check and the alignment check."
