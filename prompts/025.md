When running as a web page, the app should support two query-string parameters:

initial: a positive integer which determines how many birds to create when the simulation starts. If not present or not valid, default to 100

current: a positive integer which indicates how many birds are in the simulation at the moment. Update this (without reloading the page) each time the number of birds changes.

When running as a desktop app, it should support a /count command-line parameter, which takes a positive integer which determines how many birds to create when the simulation starts. If not present or not valid, default to 100. If the INITIAL_BIRD_COUNT environment variable is also set, the command-line value takes precedence.
