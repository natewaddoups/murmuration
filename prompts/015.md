
In Simulation.cs, TryGetNeighbor is very costly.

This cost can be reduced if we...

* create a 2D array to hold the distances between any two birds
* fill the array, taking advantage of the fact that the computing the distance from bird A to bird B also tells us the distance from bird B to bird A
* find the nearest neighbor to bird N by finding the index of the smallest value in the array of distances from bird N to all other birds.

Also, skip the "only look forward" check for candidates that fail the "closest so far" check.

Also add a per-frame Vector3[] _directions, filled at the start of Think. Bird.Direction does a quaternion transform on every access. TryGetNeighbor would use the cached direction instead, and the other b.Direction uses in Think could too.
